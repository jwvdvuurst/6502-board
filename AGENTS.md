# Shared AI guidance

This project uses reusable AI guidance maintained in [AI Hub](https://github.com/jwvdvuurst/ai-hub), you can also find it cloned in this [folder](C:\Users\JWvdV\Documents\workspace\ai-hub). 

Before making changes:

- Follow this project's local documentation and current files first; local guidance takes precedence.
- Consult the [general rules](https://github.com/jwvdvuurst/ai-hub/blob/main/rules/general_rules.md).
- Use task-relevant [skills](https://github.com/jwvdvuurst/ai-hub/tree/main/skills).
- Consult [references](https://github.com/jwvdvuurst/ai-hub/tree/main/references) and [agents](https://github.com/jwvdvuurst/ai-hub/tree/main/agents) when relevant.
- Apply only guidance relevant to the task.
